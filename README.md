## Genetic Chess Engine

Це високопродуктивний шаховий рушій, написаний на Python, який навчається за допомогою генетичного алгоритму. 

## Головні фічі рушія:
* **Алгоритм пошуку:** NegaMax з Альфа-Бета відсіканням (Alpha-Beta Pruning).
* **Евристика вбивці:** Форсований пошук (Quiescence Search) для запобігання втраті фігур під час серії розмінів.
* **Сортування ходів:** MVV-LVA (Слабкий б'є сильного) для максимальної оптимізації відсікання гілок.
* **Таблиці Транспозицій (Кеш):** Запам'ятовування вже прорахованих позицій за допомогою FEN-хешування.
* **Генетичне навчання:** Бот не має жорстко заданих оцінок позицій. Він навчився грати, граючи сам із собою тисячі партій та передаючи найкращі гени (ваги фігур та позицій) наступним поколінням.

## Як зіграти проти бота
Проєкт розроблено в середовищі Google Colab, що дозволяє запустити його прямо в браузері без встановлення Python на комп'ютер.

1. Відкрийте файл `.ipynb` з цього репозиторію в Google Colab.
2. Запустіть усі блоки коду в такому порядку: 1, 2, 4. 
3. Блок 6 запустить інтерактивну графічну дошку (chessboard.js), де ви зможете зіграти проти чемпіона!

Бота можна натренувати у блоці 5, параметри тренування можна змінити у блоці 3.

## Формат геному
Найкращі ваги, отримані в результаті еволюції, збережені у файлі `titan_champion.json`. Бот оцінює цінність фігур, контроль центру, просування пішаків та мобільність.
